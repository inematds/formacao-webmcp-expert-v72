The final project brings the pieces together: the page with tools, the MCP server with the same rule, the frozen battery, the log, the watch, and the approved catalog. The watcher is the only check that depends on the network. Without a network, it exits with 3 and the report marks "sem conclusão", not "ok".

03 · Take the kit to your site

In order. Each step has the script that proves it.

1. Rule

Pull your site's logic off the screen into a module with no DOM, like oficinas.mjs.

The page and the server import this module. Proof: superficies.mjs.

2. Doors

Swap ferramentas.mjs and servidor/mcp.mjs for your own tools, with the log (observado) on both.

Proof: observar.mjs with no personal data.

3. Battery

Write contrato.json and casos.json for your tools and freeze them.

Proof: bateria.mjs in all four modes.

4. Operations

governanca.json with owner, date, and level; watcher base recorded; neighbor decisions.

Proof: relatorio.mjs with 7/7.

ReminderPolyfill only for rehearsal, never in production. Put the origin trial token and its end date (Chrome 156) on your calendar.
