Lesson 1 · 14 min

Layered architecture revisited with the state as of Oct 2026

A site ready for agents is not an API: it is eight layers, from the ones that describe the site to the ones that protect it. The WebMCP track already had this map; here it comes back with the status of each layer as of 10/19/2026 and a script that searches your code for the evidence of each one.

Start the lesson

In this lesson you will

  1. 1The 8 layers and what each one answers
  2. 2What is stable and what is a draft as of 10/19/2026
  3. 3Search the code for evidence of each layer
  4. 4Which course in the track owns each layer

Goal: review the 8 layers with the 10/19/2026 status and find the evidence for each one in the code, in the kit and in your project.

01 · The 8 layers, from bottom to top

The first four describe the site; the last four protect it. Click each one.

Click each block in the diagram to see what it does.

02 · What changed from the old map

The area had the right layers; four labels went stale.

1. Form

The old map put "declarative, from forms" tools side by side with the imperative ones.

As of 10/16/2026 the declarative API is out of the spec: only Chrome implements it, in the trial. Experimental as of 10/19/2026.

2. Discovery

llms.txt showed up as an item to publish.

Today it is a proposal with no measured effect on citations. The decision to publish stays with the inemaSEO Track.

3. Backend

The MCP side of the old track predated the 2026-07-28 revision.

Now: no initialize and no session, server/discover and confirmation by MRTR.

4. Who teaches it

Before, the layers went to phases (Builder, Integrator, Agent Developer, Expert).

Now they go to the 6 courses by topic; the script shows the owner of each layer.

RuleStatus with a date. If the date has gone stale, reread the source before trusting it.

03 · Look for the evidence for each layer

camadas.mjs reads the files in the folder (without node_modules) and looks for a sign of each layer. It measures presence, not quality.

Terminal · the 8 layers in the kit
cd ~/projetos/formacao-webmcp-expert-v72/kit
node scripts/camadas.mjs; echo "saída: $?"

Running it in a folder without the code (the build folder, an empty folder) gives 0/8 and exit 1. The criterion fails before the work does: that is how it counts as proof.

04 · The empty-folder rehearsal

Same tool in a folder with nothing in it: the criterion has to fail.

Terminal · empty folder
cd ~/projetos/formacao-webmcp-expert-v72/kit
E=${TMPDIR:-/tmp}/ensaio-webmcp-expert/a1; rm -rf $E; mkdir -p $E
node scripts/camadas.mjs $E | tail -1; echo "saída: ${PIPESTATUS[0]}"
