Aula 5 · 14 min

Protocolos vizinhos como mapa: A2A, ACP, AP2, NLWeb, llms.txt — o que é rascunho

Toda semana aparece uma sigla nova prometendo deixar o site "pronto para IA". Quase todas estão em rascunho ou proposta, e cada uma vive numa camada diferente. Nesta aula você põe cada protocolo vizinho no mapa, com status e data, e decide para o seu site: adotar, esperar ou não se aplica.

Começar a aula

Nesta aula você vai

  1. 1Em que camada cada sigla mora
  2. 2Proposta, rascunho, projeto e estável, com data
  3. 3Adotar, esperar ou não se aplica, com motivo
  4. 4Os motivos que não valem (ranking, "vai virar padrão")

Objetivo: situar cada protocolo vizinho na camada certa com status datado e decidir adotar, esperar ou não se aplica, com motivo.

Nenhum destes é fator de ranking. Citação nas IAs é assunto da Formação inemaSEO.

02 · Como ler o status

O rótulo diz quanto você pode apostar.

1. Proposta

Alguém publicou o formato; ninguém se comprometeu a ler.

Ex.: llms.txt. Custa pouco, mas não prometa efeito.

2. Rascunho

Documento de grupo (CG, IETF) em andamento. A API já mudou uma vez (navigator → document).

Adotar = data de revisão + fallback, sempre.

3. Projeto

Tem implementação e organização por trás (Linux Foundation, empresa).

Estável não é: confira a versão no dia em que adotar.

4. Estável

Revisão publicada e versionada, com mudança anunciada (MCP 2026-07-28).

Mesmo assim, fixe a versão do SDK e rode a bateria quando subir.

Regra do scriptAdotar algo que não é estável pede revisar_em (data) e fallback.

Oficinas gratuitas: ACP e AP2 não se aplicam. Web Bot Auth espera o curso 4.

PROBLEMA WebMCP: motivo promete ranking ou padrão ("vai ser o padrão da web")
PROBLEMA WebMCP: adotar algo em rascunho pede revisar_em (AAAA-MM-DD) e fallback
PROBLEMA llms.txt: motivo promete ranking ou padrão ("sobe o site no ranking das IAs")
PROBLEMA Web Bot Auth: sem decisão
VIZINHOS: 8 protocolos · 7 decisões · 4 problema(s)
saída: 1

"Vai ser o padrão da web" e "sobe o site no ranking das IAs" não são motivos: nada no mapa é isso. Adotar WebMCP sem data de revisão e sem fallback também reprova.
