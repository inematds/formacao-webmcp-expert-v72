Aula 1 · 14 min

Arquitetura em camadas revista com o estado de out/2026

Um site pronto para agentes não é uma API: são oito camadas, das que descrevem o site às que o protegem. A área WebMCP já tinha esse mapa; aqui ele volta com o status de cada camada em 19/10/2026 e um script que procura no seu código a evidência de cada uma.

Começar a aula

Nesta aula você vai

  1. 1As 8 camadas e o que cada uma responde
  2. 2O que é estável e o que é rascunho em 19/10/2026
  3. 3Procurar evidência de cada camada no código
  4. 4Qual curso da formação é dono de cada camada

Objetivo: revisar as 8 camadas com o status de 19/10/2026 e achar no código a evidência de cada uma, no kit e no seu projeto.

01 · As 8 camadas, de baixo para cima

As quatro primeiras descrevem o site; as quatro últimas o protegem. Clique em cada uma.

Clique em cada bloco do diagrama para ver o que ele faz.

Estrutura da área WebMCP (§04), com o status relido na spec, no Chrome Status e no MCP em 19/10/2026.

02 · O que mudou no mapa antigo

A área tinha as camadas certas; quatro rótulos ficaram velhos.

1. Formulário

O mapa antigo punha ferramentas "declarativas, a partir de formulários" lado a lado com as imperativas.

Em 16/10/2026 a API declarativa está fora da spec: só o Chrome implementa, no trial. Experimental em 19/10/2026.

2. Descoberta

O llms.txt aparecia como item a publicar.

Hoje é proposta sem efeito medido em citação. A decisão de publicar fica com a Formação inemaSEO.

3. Backend

O lado MCP da formação antiga era anterior à revisão 2026-07-28.

Agora: sem initialize e sem sessão, server/discover e confirmação por MRTR.

4. Quem ensina

Antes, as camadas iam para fases (Builder, Integrator, Agent Developer, Expert).

Agora vão para os 6 cursos por tema; o script mostra o dono de cada camada.

RegraStatus com data. Se a data envelheceu, releia a fonte antes de confiar.

03 · Procurar a evidência de cada camada

camadas.mjs lê os arquivos da pasta (sem node_modules) e procura um sinal de cada camada. Mede presença, não qualidade.

Terminal · as 8 camadas no kit
cd ~/projetos/formacao-webmcp-expert-v72/kit
node scripts/camadas.mjs; echo "saída: $?"

04 · O ensaio da pasta vazia

Mesma ferramenta numa pasta sem nada: o critério tem de falhar.

Terminal · pasta vazia
cd ~/projetos/formacao-webmcp-expert-v72/kit
E=${TMPDIR:-/tmp}/ensaio-webmcp-expert/a1; rm -rf $E; mkdir -p $E
node scripts/camadas.mjs $E | tail -1; echo "saída: ${PIPESTATUS[0]}"

05 · Prática

O kit primeiro, depois o seu projeto. Cada exercício termina num pronto quando.

E1 · As camadas no kit

5 min

Instale o kit (aula 2, bloco de instalação) e rode o bloco das camadas.

Pronto quando: node scripts/camadas.mjs; echo "saída: $?" → CAMADAS: 8/8 com evidência e saída: 0.

E2 · O critério falha antes

2 min

Rode o ensaio da pasta vazia.

Pronto quando: O bloco imprime CAMADAS: 0/8 com evidência e saída: 1.

E3 · As camadas do seu projeto

15 min

Rode o script na pasta do seu site e anote, para cada camada com "falta", a aula ou o curso que a resolve.

Pronto quando: node scripts/camadas.mjs [pasta do seu site] imprime a linha CAMADAS: N/8 com evidência, e o arquivo camadas-[seu site].md tem uma linha por camada que falta.
