Aula 4 · 18 min

Bateria congelada das suas ferramentas e regressão quando a spec muda

Quando o código ou a spec mudam, o site com WebMCP falha em silêncio: a detecção não acha a API, cai no formulário e ninguém vê. Só uma bateria pega. Nesta aula você congela o contrato e os casos das ferramentas, roda nos quatro modos e vê a bateria pegar o nome antigo da API.

Começar a aula

Nesta aula você vai

  1. 1O que é congelar e por que o hash
  2. 2Os quatro modos: sem, polyfill, nativo e MCP
  3. 3A regressão silenciosa do nome antigo
  4. 4O que fazer quando o esperado muda de verdade

Objetivo: congelar contrato e casos das suas ferramentas, rodar nos quatro modos e ver a bateria pegar a regressão do nome antigo da API.

01 · Da bateria congelada ao veredito

Clique em cada etapa.

Clique em cada bloco do diagrama para ver o que ele faz.

A bateria do curso 2 testa a página; esta testa página e servidor contra um contrato que não muda sem decisão.

02 · Regras de uma bateria que vale

Herdadas da LOOP-R Engenharia (testes congelados) e aplicadas às ferramentas.

1. Congelada

O esperado não muda para o teste passar. Mudou a spec ou a regra? Recongele e explique no commit.

O hash torna a mudança visível: ninguém altera casos.json sem a bateria recusar.

2. Sem modelo

Os casos chamam as ferramentas direto (executeTool, tools/call), como um agente faria.

Nada de modelo no circuito: o mesmo código dá o mesmo veredito.

3. Modo sem

A rodada sem API prova que a pessoa reserva pelo formulário.

É a primeira linha da bateria, antes de qualquer agente.

4. Spec mudou

Spec nova, Chrome novo ou SDK novo: rode a bateria antes de tudo.

A vigia da aula 6 avisa quando é hora.

Ordemvigia acusa → bateria → ler o que mudou → corrigir ou recongelar com motivo

04 · A regressão silenciosa: o nome antigo

navigator.modelContext é o nome antigo (antes do PR #177, aceito em 19/05/2026). Uma cópia da página com ele: o site continua funcionando, e só a bateria percebe.

Terminal · página com o nome antigo
cd ~/projetos/formacao-webmcp-expert-v72/kit
E=$(bash scripts/copia.sh a4)
# a regressão: alguém cola um exemplo antigo que usa o nome de antes de 19/05/2026
sed -i 's/const mc = document.modelContext; /const mc = navigator.modelContext; /' $E/pagina/ferramentas.mjs
cd $E && node scripts/bateria.mjs sem nativo | grep -E "FALHA|ok    \[sem\]|BATERIA"; echo "saída: ${PIPESTATUS[0]}"
Exemplo do repositório

ok    [sem] fallback: a pessoa reserva pelo formulário
